    What it does

    Nothing is erased
    Files you set aside are moved to a _to_delete folder inside the folder you are cleaning. Empty it when you are sure.
    Preview before you decide
    Photos appear the right way round, even from a phone. Videos show a still frame with length and resolution, and can play muted in the window.
    Undo at any time
    Press Z to take back the last decision, even after the final file.
    Made for the keyboard
    Arrow keys or K and D to decide, Space to play a video, O to open the file in your usual player.
    Safe with duplicates
    If a file with the same name already waits in _to_delete, the new one is renamed instead of overwriting it.

    Install

    You need Python 3.8 or newer. The two packages in requirements.txt are optional and add image and video previews.

    $ git clone https://github.com/skullypng/Keep-or-Delete-File-Cleaner.git
$ cd Keep-or-Delete-File-Cleaner
$ pip install -r requirements.txt
$ python keep_or_delete.py

    On Linux you may also need sudo apt install python3-tk.
