Your files, your control

Set aside doesn't mean gone forever.

Files marked for removal are moved into a separate folder, so you can review them again before deciding what to delete permanently.

✓Files marked for removal go to _to_delete
✓Existing files are not silently overwritten
✓Hidden and system files are skipped
✓You can undo your decisions
The simple workflow

Three steps. More breathing room.

Start the desktop app and tidy up your folder one file at a time.

01 / OPEN

Choose a folder

Launch Keep or Delete and select the folder you want to review.

02 / REVIEW

Keep or set aside

Look at each file and make a choice with a click or keyboard shortcut.

03 / DONE

Review your selection

Take one last look inside _to_delete before removing anything permanently.

Ready when you are

Make room for what matters.

Open source and designed to run locally with Python.

# Clone the repository
git clone https://github.com/skullypng/Keep-or-Delete-File-Cleaner.git
cd Keep-or-Delete-File-Cleaner

# Install dependencies (optional for previews)
pip install -r requirements.txt

# Launch the app
python keep_or_delete.py
